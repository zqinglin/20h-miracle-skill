# 图表与排版

遵循用户提供的目标期刊或会议模板；以下是既定排版偏好，不是未经核实的会议官方规则。

- 单栏表用 `\columnwidth` 或适合当前环境的 `\linewidth`，双栏表用 `\textwidth`，优先 `tabularx` 填满所在栏宽。不要用 `\resizebox` 强行缩小字体，也不要为填宽而制造异常宽列。
- 模板允许时，表格统一 `\small`。使用 booktabs 的 `\toprule`、`\midrule`、`\bottomrule`，必要时分组表头与 `\cmidrule`，避免竖线和密集网格。
- 检查数值对齐、列宽、长方法名换行、表头、空白和视觉平衡；新增命令时确认依赖包可用。
- 图中文字优先 Times New Roman 或兼容字体，目标模板有明确字体要求时遵循模板，以论文最终显示尺寸检查可读性。保证清晰度，裁减无意义留白，图例简洁，不机械加粗本方法所有元素。
- 多子图的比例按内容、标签长度和最终显示尺寸调整。坐标范围应服务真实比较，不隐藏不利数据。
- 图注说明图示内容、子图含义、指标方向、符号与必要设置；正文解释观察及意义，避免逐句重复。
- 每张图有明确论证作用：流程图解释方法，主结果图支持性能比较，比较图展示不同条件的结果，定性图提供视觉证据，机制图解释关键行为。
- 若实际制作科学图且环境提供 figure-skill，按该技能处理绘图细节；单纯改文字不必加载绘图流程。

- 调整表格宽度时优先使用列宽权重、`\tabcolsep`、表头设计、合理换行和 `tabularx`。分组表头按实际指标类别组织，不固定套用项目专属指标。
- 修改表格即使只涉及一个数值或宽度，也交付完整可替换的 LaTeX 表格代码。
- 图表形式按数据结构和表达目标选择；难读或视觉效果不佳时重新选择，不机械沿用。具体图片的比例要求不推广为所有图的固定比例。
- 图例、标签和表格仅展示理解当前分析必要的信息；同时清楚区分参与比较的设置和变体，避免省略关键条件造成误导。
